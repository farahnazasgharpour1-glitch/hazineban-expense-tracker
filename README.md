# هزینه‌بان — داشبورد مدیریت هزینه‌ها

هزینه‌بان یک نمونه‌کار فرانت‌اند فارسی و راست‌چین برای ثبت، دسته‌بندی، پیگیری و تحلیل هزینه‌هاست. پروژه با HTML، CSS و JavaScript خام نوشته شده و برای اجرا به کتابخانه، CDN یا سرویس خارجی نیاز ندارد.

## قابلیت‌ها

- ثبت، ویرایش، حذف و تغییر وضعیت هزینه‌ها (در انتظار، تأییدشده و ردشده)
- ورود تاریخ و ماه بودجه با تقویم شمسی؛ نگهداری تاریخ‌ها در قالب ISO در فضای ذخیره‌سازی
- قالب‌بندی ارقام ریالی و اعتبارسنجی مبلغ با محدودیت عدد صحیح امن JavaScript
- بودجه جداگانه برای هر ماه با هشدار در آستانه ۸۰٪ و عبور از ۱۰۰٪
- کارت‌های آماری، نمودار میله‌ای و نمودار دونات با SVG و CSS
- جست‌وجو با debounce، فیلتر بر اساس دسته/وضعیت/بازه تاریخ، مرتب‌سازی و صفحه‌بندی
- خروجی CSV سازگار با Excel، همراه با BOM و محافظت در برابر CSV Formula Injection
- گزارش ماهانه قابل چاپ و ذخیره به PDF از پنجره چاپ مرورگر
- پشتیبان‌گیری و بازیابی هزینه‌ها و بودجه‌ها با فایل JSON
- بارگذاری داده‌های نمونه برای نمایش امکانات به کارفرما
- حالت روشن و تاریک با ذخیره انتخاب کاربر
- طراحی واکنش‌گرا، جدول کارتی در موبایل، پشتیبانی از کاهش حرکت و منوی موبایل قابل دسترس
- تنظیمات CSP و هدرهای امنیتی برای میزبان‌های سازگار

## اجرا

فایل `index.html` را در مرورگر باز کن. برای تجربه کامل‌تر و تست ذخیره‌سازی، بهتر است پروژه از یک وب‌سرور محلی یا میزبانی استاتیک ارائه شود.

## نمایش به کارفرما

از بخش «داده‌های نمایشی» گزینه «بارگذاری داده نمونه» را انتخاب کن تا داشبورد با اطلاعات ساختگی و غیرحساس پر شود. این عملیات اطلاعات فعلی را جایگزین می‌کند؛ اگر داده واقعی داری، پیش از آن از بخش «پشتیبان‌گیری» فایل JSON دریافت کن.

داده‌های نمونه با برچسب «نمونه» از داده‌های واقعی متمایز می‌شوند. اطلاعات نمونه ساختگی‌اند و به شرکت یا شخص واقعی اشاره ندارند.

## گزارش PDF

از بالای داشبورد «گزارش چاپی / PDF» را انتخاب کن. در پنجره چاپ مرورگر، مقصد چاپگر را روی **Save as PDF / ذخیره به‌صورت PDF** قرار بده.

## محدودیت‌ها و ملاحظات امنیتی

- این پروژه یک دمو و نمونه‌کار Front-end است؛ اطلاعات در LocalStorage همان مرورگر و همان دستگاه ذخیره می‌شوند و به سرور ارسال یا بین دستگاه‌ها همگام نمی‌شوند.
- LocalStorage رمزنگاری‌شده نیست. اطلاعات حساس، داده‌های واقعی سازمانی یا اطلاعات شناسایی‌کننده را در نسخه عمومی وارد نکن.
- برای استفاده سازمانی واقعی، احراز هویت، نقش‌ها و مجوزها، ثبت رویدادها، همگام‌سازی و پایگاه داده به بک‌اند امن نیاز دارند.
- فایل پشتیبان JSON حاوی همه هزینه‌ها و بودجه‌های ذخیره‌شده است؛ آن را مانند یک فایل حساس نگهداری کن.
- بازیابی فایل پشتیبان اطلاعات جاری را جایگزین می‌کند و ساختار فایل و رکوردها پیش از ذخیره اعتبارسنجی می‌شود.
- خروجی CSV برای جلوگیری از اجرای فرمول‌های ناخواسته در برنامه‌های صفحه‌گسترده، مقادیر متنی با شروع `=`, `+`, `-` یا `@` را خنثی می‌کند.
- این صفحه عمداً `noindex` است، زیرا محتوای اصلی داشبورد تعاملی و وابسته به JavaScript است. برای SEO، یک صفحه معرفی پروژه با متن توضیحی، تصاویر و لینک دمو در پورتفولیوی اصلی قرار می‌گیرد.
- پس از مشخص‌شدن آدرس نهایی دمو، `canonical` و نشانی مطلق تصویر Open Graph باید به همان دامنه تنظیم شوند؛ URL فرضی در فایل‌ها قرار داده نشده است.

## فناوری‌ها

HTML5 · CSS3 · JavaScript (Vanilla) · LocalStorage · SVG · Blob / File API · Window Print API · Intl Persian Calendar

فونت Estedad با وزن Regular در پوشه assets/fonts نگهداری می‌شود؛ در ZIP اولیه فقط همین وزن موجود بود، بنابراین وزن‌های جداگانهٔ 500 و 700 به‌صورت ساختگی یا با فایل نامعتبر اضافه نشده‌اند.


## نسخه ۲.۲ — بازطراحی چندصفحه‌ای

ساختار رابط به پنج مسیر مستقل تقسیم شده است: `index.html` (داشبورد)، `expenses.html` (مدیریت هزینه‌ها)، `budget.html` (بودجه)، `reports.html` (تحلیل و گزارش) و `settings.html` (پشتیبان‌گیری و تنظیمات). در دسکتاپ ناوبری کناری و در موبایل نوار پایین پنج‌گزینه‌ای نمایش داده می‌شود. فرم ثبت/ویرایش در دسکتاپ به‌شکل پنل کشویی از سمت راست و در موبایل تمام‌صفحه باز می‌شود. داده‌ها و تنظیمات همچنان با همان کلیدهای LocalStorage نسخهٔ قبل نگهداری می‌شوند و بین صفحات همین مبدأ به اشتراک گذاشته می‌شوند.

برای مشاهده محلی، این پوشه را از طریق یک وب‌سرور استاتیک (مثلاً Live Server) اجرا کنید و `index.html` را باز کنید.


## نسخه ۲.۳ — بهبود خوانایی و راهنمای استفاده

- اندازه تایپوگرافی در دسکتاپ در مقیاس یکپارچه بزرگ‌تر شده؛ شامل تیترها، جدول، فرم‌ها، فیلترها، دکمه‌ها و متن‌های توضیحی.
- کنتراست نوشته‌های کم‌رنگ و دکمه‌های ثانویه در هر دو پوسته روشن و تاریک تقویت شده است.
- سربرگ خلوت‌تر شده؛ عنوان صفحه و تاریخ با فاصله مشخص نمایش داده می‌شوند و برچسب تکراری «پنل کنترل مالی» حذف شده است.
- برای هر صفحه یک توضیح کوتاه و لینک راهنمای مرتبط اضافه شده است.
- صفحه مستقل `help.html` راهنمای شروع، ثبت هزینه، بودجه، گزارش‌گیری، پشتیبان‌گیری و نکات حریم خصوصی را توضیح می‌دهد.
- راهنما از منوی کناری دسکتاپ، میان‌بر داشبورد و صفحه تنظیمات در دسترس است؛ نوار پایین موبایل همچنان پنج گزینه اصلی و خلوت خود را حفظ می‌کند.

همه داده‌ها و کلیدهای LocalStorage نسخه ۲.۲ حفظ شده‌اند.
